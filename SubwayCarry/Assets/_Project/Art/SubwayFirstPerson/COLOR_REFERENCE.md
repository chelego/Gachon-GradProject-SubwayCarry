# Subway_3D colour reference

Visual reference: Korail Class 351000 first-batch interior photograph by IMKSv (Wikimedia Commons).
https://commons.wikimedia.org/wiki/File:Korail_Class_351000_EMU_1st_Batch_Interior.jpg

The reference was viewed for colour direction; the photograph is not used as a game texture.

- Light grey rubber floor: #B9C0C1, existing fine grain retained.
- Blue regular seats: #3B5DB0, existing woven texture retained.
- Red priority seats: #B95762.

These materials are assigned only to Subway_3D. Original ochre/rose materials remain available for older 3D backups.

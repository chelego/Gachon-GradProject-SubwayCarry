# QuarterView_Test

2:1 아이소메트릭 투영을 사용한 2D 쿼터뷰 역사 구조와 화면 전환을 확인하기 위한 독립 Prototype

## 실행 Scene

- `QuarterView_Test.unity`

Scene을 다시 생성하려면 Unity 메뉴에서 다음을 실행함.

```text
SubwayCarry > Prototype > Build Quarter View Test
```

## 조작

- `WASD`: 이동
- 마우스: 바라보는 방향
- `E`: 중앙 개찰구에 교통카드 태그
- 카메라: 플레이어가 화면 중앙 안전 영역을 벗어날 때만 맵 경계 안에서 추적

## 맵 구성

- `MAP 1 - Isometric Fare Gate Concourse`
  - 외부 입구 계단 도착 지점
  - 발권기, 역무실, 엘리베이터와 기둥
  - 전체 폭을 막는 개찰구와 중앙 상호작용 통로
  - 상행·하행 승강장 계단
- `MAP 2 - Isometric Bidirectional Platforms`
  - 같은 크기의 양쪽 승강장
  - 중앙의 방향별 2개 철로
  - 역사 양끝의 열차 진입·진출 터널과 역사 바깥까지 이어지는 철로
  - 승강장 안전선과 스크린도어
  - 기둥, 벤치와 각 방향 계단
  - 기존보다 약 1.5배 넓힌 보행 가능 승강장 폭
  - 플랫폼 진입 시 양쪽 터널에서 서로 반대 방향으로 들어와 정차하는 4량 열차 동선 미리보기

계단 Trigger에 들어가면 페이드아웃 후 다른 맵 하나만 활성화하고, 연결된 계단 도착 지점에서 페이드인한다. 플랫폼 계단으로 다시 개찰구층에 돌아올 수 있다.

## 범위

- 승객 AI와 정식 열차 문·탑승 로직은 포함하지 않는다. 열차는 진입 공간과 이동축 검증용 미리보기다.
- 최종 그래픽 Asset이 아니라 공간 비율, 이동, 충돌과 층 전환을 검증하는 회색 박스아트다.
- 관련 Scene, Script, Material은 모두 이 폴더 아래에 둔다.
- 맵 구조물은 논리 바닥 좌표를 아이소메트릭 화면 좌표로 투영하고, 윗면과 양쪽 옆면을 따로 그려 높이를 표현한다.
- 기둥과 의자는 초석·좌석처럼 바닥에서 떨어진 부품을 높이 오프셋으로 쌓으며, 플레이어는 발 위치 기준으로 구조물 앞뒤에 정렬된다.
